# Security and publication boundary

Do not commit credentials, bot tokens, chat IDs, private keys, seed phrases, production databases, logs, browser profiles or client data. Use credentials.example.json only as a schema. Keep runtime data outside the Git checkout.

This package uses public blockchain reads; it requires no wallet signing key. Telegram credentials are the only scanner notification secret. A report-supplied PASS label cannot authorize alerts: the scanner recomputes admission from evidence and freshness. UNKNOWN does not become PASS. Authorized non-blocking background UNKNOWN is explicitly disclosed.

Report a vulnerability privately to the repository owner through an existing private contact channel. Do not put secrets or exploit credentials into public GitHub issues. No public security email is invented here.

No license grant is bundled yet. Public visibility permits viewing and platform-supported access; it is not a claim of unrestricted reuse rights.
