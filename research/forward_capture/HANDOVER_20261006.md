## 4. Cohort and timing
Common completed scoring cycle is the index time. All score-ready inputs are captured before the first security review, within the disclosed capped scanner feed. History/base/price-history admission failures are counted. A missing pair/provider failure invalidates the cycle and pauses the pilot. First qualification, controls, later-alert handling and zero-match retention follow the protocol. This refactors the prior interleaved review order and can delay the first risk review; existing screening freshness and model-ledger admission rules remain unchanged.

## 5. Leakage and privacy
Strict fields, exact raw-input hashes and unchanged scorer replay are checked before atomic admission. Runtime data is separate from the production/model database, outside git, directory0700/database0600. Only count-only status is exposed; endpoints, mint rows and input history remain private. Activation reads identities from launches/snapshots/V2 cases only through SQLite mode=ro/query_only; it never reads `pl_*` predictions or results. Exclusion cutoff precedes the read snapshot, permitting conservative additional exclusions for concurrent new registrations.

## 6. Identical endpoint mechanics
Receipts are captured immediately after each already existing provider batch response. No additional HTTP/RPC call or follow-up token selection is introduced. Store only positive finite same-pair observations in frozen cohort endpoint windows; invalid or unavailable evidence stays missing. Tests prove receipt placement and identity/timing rules, not empirical fetch symmetry or continuous path coverage. Real differential availability is a pilot gate.

## 8. Resource and integrity limits
100 ms SQLite busy timeout,512 MiB runtime-file cap and 2 GiB minimum free disk. Failures pause the pilot with a count-only private marker and do not propagate into alerts. Indexed exclusions avoid reloading a large list every cycle; a 100,000-exclusion fixture uses bounded metadata. Full chain/exclusions/source binding verify on process open, then cached anchor/new suffix checks on append. Privileged old-prefix changes are not guaranteed to be detected at each append; restart/full audit detects them. The private runtime is not externally notarized. Do not automatically clear pause markers or extend the pilot.
